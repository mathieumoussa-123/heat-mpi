# Part 1 AI work log checklist — not a substitute for the full required transcript

Before committing:
- Export the **complete** prompt and complete assistant response for this interaction.
- Record UTC/local time with zone, model, tool, team member, file modifications/line ranges.
- Include build/test outputs, human review/corrections, and numerical results.
- Append to existing `llm_log/` history; do not replace it.
- Do not include passwords, tokens, personal secrets, or SSH private keys.
